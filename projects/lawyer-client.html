My final year project at COMSATS: a web platform that helps clients find the right lawyer by expertise and search criteria, built end to end from database to interface.

01 / the problemThe problem

Finding a lawyer usually depends on word of mouth. A client with a specific legal issue has no easy way to compare lawyers by what they actually practice. The platform brings both sides together and matches them on expertise and search parameters.

02 / what i builtWhat I built

Matching & searchClients find lawyers by area of expertise and other search criteria.
REST APIExpress endpoints for secure data exchange between the React front end and the database.
Data modelMongoDB schemas for clients, lawyers and their interactions.
PaymentsAPI endpoints for payment processing.

03 / architectureArchitecture

ReactSingle-page front end
Node.js + ExpressREST API
MongoDBDocument database

I set up production-like environments: environment variables for secrets and configuration, CORS policies between front end and API, and server deployment configuration.

04 / what i learnedWhat I learned

  • Designing a full MERN application from the schema up.
  • Building and securing REST APIs.
  • Configuration management across environments — an early taste of the DevOps side of software.
